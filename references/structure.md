# 开题报告结构规范

## 一、通用七部分骨架

绝大多数中文高校本科毕业论文开题报告采用"七部分 + 进度安排"，差异只在栏目名称与是否需要封面。

```
一、本课题研究意义
    （一）理论意义
    （二）实践意义
二、国内外有关本课题的研究动态
    （一）国外研究进展
    （二）国内研究进展
    （三）研究空白
三、本课题研究的基本内容          1. 2. 3. 4.
四、本课题拟解决的主要问题        1. 2.
五、研究方法                     1. 2. 3.（每个方法内部再分三段）
六、主要创新点                    （1）（2）
七、主要参考文献                  [1] … [n]
研究进度安排                      日期 + 工作内容
```

### 编号层级（三级，不可混用）

| 层级 | 写法 | 用途 |
|---|---|---|
| 一级 | 一、二、三 | 七大部分 |
| 二级 | （一）（二） | 意义、动态、内容内部 |
| 三级 | 1. 2. 3. | 研究内容条目、研究方法条目 |

⚠️ 「三、本课题研究的基本内容」下面若再用「一、二、三」，会与一级标题同级混淆。要么用 `1. 2. 3.`，要么用 `（一）（二）`。

## 二、字数配额

以 5000 字左右的开题报告为基准（各校要求不同，按比例缩放）：

| 部分 | 建议字数 | 硬约束 |
|---|---|---|
| 研究意义 | 600—900 | 不引文献、不堆病例数 |
| 国内外动态 | 1200—1600 | 国外/国内各半，各带"综上"收尾 |
| 研究内容 | 150—250 | 4 条以内，每条一句 |
| 拟解决的主要问题 | 200—350 | 只留 1 个核心 |
| 研究方法 | 1200—1500 | 3 个方法，每个三层 |
| 创新点 | 200—300 | 1—2 条，与他人研究对比 |
| 参考文献 | 30—40 条 | 按首次出现顺序 |
| 进度安排 | 150—250 | 6 段左右 |

超出配额时优先压缩：研究意义的现象罗列 → 动态的重复描述 → 方法的应用细节，**不要压"综上"句与边界声明**，那两句是评审的判断依据。

## 三、两种常见栏目变体

### 变体 A：纯段落式（文字版）

七部分全是段落，无表格。适合模板本身不带表格的学校（如河南大学 2027 届模板）。
排版：一级标题黑体四号加粗、二级黑体小四、正文宋体小四、1.5 倍行距、首行缩进 2 字符。

### 变体 B：表格式（规范版）

在七部分之外增加 5—6 张三线表，常见组合：

| 表号 | 表名 | 作用 |
|---|---|---|
| 表 1 | 拟解决的关键问题与对应措施 | 把"问题—对策"一一对齐 |
| 表 2 | 研究目标与研究内容对应关系 | 防止目标与内容脱节 |
| 表 3 | 研究方法与具体应用 | 方法与阶段、数据来源对齐 |
| 表 A | 关键字段可得性核验表 | 证明分层变量有数据支撑（见下） |
| 表 4 | 可行性分析 | 理论/资料/方法/条件四角度 |
| 表 5 | 研究进度安排 | 四列：阶段、时间、主要工作、阶段成果 |
| 表 6 | 指导教师审核意见 | 签字栏 |

### 表 A：关键字段可得性核验表（文献研究型课题专用）

导师最常质疑"你表格里那些字段，原文里有吗？"。这张表就是回答。

列：`字段 | 原始文献报告篇数 | 报告率 | 处理方案`
行：年龄、性别、给药途径、溶剂体积、剂量、疗程、合并用药、过敏史、发生时间、严重程度、转归、因果判定、盐型

处理方案分档：

- 报告率 ≥ 80%：可作定量分层
- 50%—80%：可描述，慎作分层
- **< 50%：仅作定性归纳**，不得承诺分层比较

生成方式：把纳入文献的 OCR 文本按关键词扫描，人工复核命中项，得到"篇数/总数"。

## 四、参考文献编号规则

1. 按**正文首次出现顺序**编号，从 [1] 开始连续递增
2. 同一文献多处引用复用同一编号
3. 正文标注用**上标**，如 `……风险约为 0.17%` + 上标 `[3]`（不是"（Sangiorgio，2024）"）
4. 文末声明与正文实际一致，不得写"全部条目均被引用"而实际有孤条
5. 附录、致谢不计入编号

## 五、与学校模板的差异处理

- 模板缺封面：按模板骨架输出正文，另询是否需要加封面页，不擅自加
- 模板有占位符（如"Z 例""Y 注射液"）：替换为真实内容；若真实信息未定（如课题来源），保留占位并在交付说明中用 ⚠️ 标出
- 模板页边距/字号：一律沿用模板，不"美化"成自己的偏好
